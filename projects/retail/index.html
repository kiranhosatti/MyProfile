A batch ETL pipeline that ingests daily retail sales files and turns them into analytics-ready tables: sales by store, by category, and by day, plus supporting dimension tables for products and stores.

Apache Airflow owns the orchestration — sensing for new daily files, kicking off PySpark transformation jobs for each Medallion layer, running data-quality checks between layers, and alerting on failure. Curated Gold tables are queried through Athena and Redshift depending on the use case.

Why this project

Built to practice production concerns that toy pipelines usually skip: DAG idempotency, backfilling historical partitions, and handling a schedule that has to run reliably every day rather than once.
