Pipeline stages

1. Ingestion

Daily sales export files (one per store) are dropped into an S3 raw zone by an upstream (simulated) point-of-sale system.

2. Sensing

An Airflow DAG uses a sensor to detect that the day's files have all landed before triggering downstream tasks.

3. Bronze

A PySpark task reads the raw files and writes them to a Bronze zone, partitioned by sale date and store.

4. Silver

A PySpark task cleans and conforms the data: currency normalization, deduplication of line items, and joins against product and store dimension tables.

5. Gold

Aggregated tables are built — daily sales by store, by category, and month-to-date rollups.

6. Data quality checks

Row-count and null-rate checks run between each layer; the DAG fails fast and alerts if a check doesn't pass.

7. Serving

Gold tables are queried via Athena for exploration and loaded into Redshift for dashboarding.
