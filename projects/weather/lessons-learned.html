What I'd tell someone starting this project

  • The pandas Lambda layer alone gets close to Lambda's unzipped size limit, so pinning a slim pandas build and stripping test/doc files from the layer was necessary.
  • Most early failures were CloudFormation stack rollbacks caused by small IAM permission gaps — reading the failed-resource reason in the console became step one for every debug session.
  • Keeping the fetch and transform logic in one Lambda kept the project simple, but a follow-up version would likely split them so a transform bug doesn't require re-fetching from the API.
  • Storing the AWS deploy role as a GitHub Actions secret (rather than long-lived access keys) made the CI/CD loop noticeably less risky to leave running unattended.
