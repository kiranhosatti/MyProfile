Pipeline stages

1. Trigger

An Amazon EventBridge scheduled rule invokes the Lambda function on a fixed interval (e.g. hourly).

2. Fetch

The Lambda function calls the Open-Meteo public API for a fixed set of locations and receives the current and forecast weather data as JSON.

3. Raw storage

The raw JSON response is written directly to an S3 raw zone, partitioned by date and hour, before any transformation.

4. Transform

The same Lambda function (using a pandas Lambda layer) flattens and converts the JSON into Parquet.

5. Processed storage

Parquet output is written to a processed zone in S3, ready for querying with Athena.

6. CI/CD

On every push to the repository, a GitHub Actions workflow packages the Lambda function and its pandas layer, and deploys both via CloudFormation.
