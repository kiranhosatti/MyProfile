Lambda handler: fetch + write to S3

import json
import urllib.request
import boto3
from datetime import datetime

s3 = boto3.client("s3")
BUCKET = "weather-pipeline-raw"

def lambda_handler(event, context):
    url = (
        "https://api.open-meteo.com/v1/forecast"
        "?latitude=12.97&longitude=77.59&current_weather=true"
    )
    with urllib.request.urlopen(url) as response:
        data = json.loads(response.read())

    now = datetime.utcnow()
    key = f"raw/{now:%Y/%m/%d}/{now:%H}.json"
    s3.put_object(Bucket=BUCKET, Key=key, Body=json.dumps(data))

    return {"statusCode": 200, "key": key}

GitHub Actions: build and deploy (excerpt)

name: deploy-lambda
on:
  push:
    branches: [main]

jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: aws-actions/configure-aws-credentials@v4
        with:
          aws-region: ap-south-1
          role-to-assume: ${{ secrets.AWS_DEPLOY_ROLE }}
      - name: Package pandas layer
        run: ./scripts/build_layer.sh
      - name: Deploy stack
        run: |
          aws cloudformation deploy \
            --template-file template.yaml \
            --stack-name weather-pipeline \
            --capabilities CAPABILITY_IAM
