A small serverless pipeline that pulls current and forecast weather data from the free Open-Meteo API on a schedule, using a single AWS Lambda function, and lands both raw and processed data in Amazon S3.

An EventBridge scheduled rule triggers the Lambda function, which calls the API, writes the raw JSON response to a raw zone in S3, then converts it to Parquet (using a pandas Lambda layer) for a processed zone. Infrastructure is defined in CloudFormation, and GitHub Actions builds, tests and deploys the Lambda function and its layer on every push.

Why this project

This was the first fully serverless, fully automated pipeline in the portfolio — built to get comfortable with Lambda packaging, layer size limits, and a real CI/CD deployment loop rather than manual console deploys.
