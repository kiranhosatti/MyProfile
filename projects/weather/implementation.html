Implementation notes

Everything runs in a single Lambda function to keep the project simple: fetch, then transform, in one invocation. A pandas layer (packaged separately, since pandas exceeds Lambda's inline size limit) is attached to the function for the Parquet conversion step.

Infrastructure — the Lambda function, its execution role, the EventBridge rule, and the S3 bucket — is defined in a CloudFormation template so the whole stack can be created or torn down with a single command.

GitHub Actions runs on every push: it installs dependencies, packages the pandas layer, zips the function code, and deploys via aws cloudformation deploy.
