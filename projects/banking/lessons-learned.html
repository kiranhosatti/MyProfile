What I'd tell someone starting this project

  • Idempotent Lambda triggers mattered a lot here — S3 can occasionally deliver duplicate event notifications, so every downstream step needed to tolerate being run twice.
  • Step Functions' built-in retry and catch blocks removed a surprising amount of custom error-handling code compared to chaining Lambdas directly.
  • Athena was the right tool for ad hoc exploration, but Redshift's star schema was a better fit once reporting needed repeatable joins across customers, accounts, and transactions.
  • Treating PII carefully from day one (synthetic data only, least-privilege IAM roles) was far easier than retrofitting it later.
