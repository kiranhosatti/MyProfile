Pipeline stages

1. Ingestion

KYC documents and transaction batch files are uploaded to an S3 raw zone, which triggers a Lambda function via an S3 event notification.

2. Orchestration

The Lambda function starts a Step Functions execution that coordinates the rest of the pipeline as a state machine, with retry and error-handling states built in.

3. Bronze

Raw KYC and transaction records are copied as-is into a Bronze zone in S3, partitioned by ingestion date.

4. Silver

A Glue (PySpark) job validates required KYC fields, checks values against expected formats, flags incomplete records, and deduplicates transactions by transaction ID.

5. Gold

Curated tables are produced: a customer risk/completeness summary and a cleaned transaction ledger, both ready for reporting.

6. Serving

Gold tables are queried through Athena for ad hoc analysis and loaded into Redshift for structured regulatory-style reporting.
