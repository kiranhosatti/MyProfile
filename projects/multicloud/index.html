This project pulls data from a REST API and moves it through two clouds end to end: raw ingestion into Azure, transformation in Databricks, and final serving from AWS. The goal was to get hands-on with a realistic scenario where an organization has existing investment in Azure for data engineering but standardizes on AWS for analytics and BI tooling.

The pipeline follows a Medallion Architecture (Bronze → Silver → Gold) inside Databricks, then hands the curated Gold layer off to AWS, where AWS Glue catalogs it and Amazon Athena serves it for SQL-based analysis.

Why this project

Most portfolio pipelines stay inside a single cloud. This one was built specifically to practice cross-cloud data movement, credential/network boundaries, and keeping a single source of truth for schema and data quality when two ecosystems are involved.
