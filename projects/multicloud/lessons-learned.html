What I'd tell someone starting this project

  • Schema drift between Bronze and Silver needed an explicit, version-controlled contract — letting Delta's schema evolution handle everything silently caused surprises downstream.
  • Moving data between clouds has a real dollar and latency cost; batching the Gold export rather than syncing continuously kept this manageable.
  • Without a single cross-cloud orchestrator, dependency management between the Databricks side and the Glue/Athena side had to be handled with clear success markers (e.g. a _SUCCESS file) rather than a shared scheduler.
  • Right-sizing the Databricks cluster mattered more than expected — an oversized cluster for a small daily dataset was the single biggest avoidable cost in the whole pipeline.
