Pipeline stages

1. Ingestion

A scheduled job calls the source REST API and writes the raw JSON response into the raw zone of Azure Data Lake Storage Gen2.

2. Bronze (Databricks)

A Databricks notebook reads the raw files as-is (schema-on-read) and writes them out as Delta tables, preserving the original structure and adding ingestion metadata (load timestamp, source file).

3. Silver (Databricks)

A second notebook cleans and conforms the Bronze data: type casting, null handling, deduplication, and flattening of nested JSON fields into a tabular structure.

4. Gold (Databricks)

Business-level aggregates and dimensional tables are built from Silver, ready for consumption.

5. Cross-cloud handoff

Gold Delta tables are exported and copied into an Amazon S3 bucket, which acts as the boundary between the Azure and AWS sides of the pipeline.

6. Cataloging (AWS Glue)

An AWS Glue crawler scans the S3 Gold zone and registers the tables and their schemas in the Glue Data Catalog.

7. Serving (Athena)

Amazon Athena queries the Gold tables directly against S3 via the Glue Catalog, with no additional data movement required.
